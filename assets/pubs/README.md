# Publication thumbnails

Put one PNG per paper here, named after the `id` in `assets/js/data.js`:

```
assets/pubs/agentgrad.png
assets/pubs/context-blindness.png
assets/pubs/collamo.png
assets/pubs/rmcd.png
assets/pubs/deepvideo-r1.png
assets/pubs/vidchain.png
```

Recommended size: about 800 × 600 px (4:3), white background. If a file is missing,
the site shows a navy placeholder with the venue name instead, so nothing breaks.

Tip: the lab homepage repo (`mlv-homepage`) already has figures for these papers
(Notion "Thumbnail File") — copy them here and rename.
